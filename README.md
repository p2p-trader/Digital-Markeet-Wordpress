# Digital Marketplace Pro 4.0.0

A complete UI/UX rebuild for a WordPress digital-goods marketplace.

## Positioning
Designed for storefronts selling digital subscriptions, software, licenses, hosting resources, templates, plugins, creative assets, courses and other online goods. The visual language uses modern premium SaaS/e-commerce patterns rather than copying any specific brand.

## Included
- Premium conversion-focused homepage
- Dark/light mode
- Responsive navigation and mobile menu
- Hero search and popular categories
- Product discovery and product cards
- Featured and trending collections
- Trust/value strip
- Promotional landing section
- Use-case section for entertainment, productivity, creators and online business
- How-it-works section
- FAQ section
- Premium newsletter and footer
- Redesigned WordPress customer login page
- Existing product archive, single-product, cart, checkout and account templates retained
- Existing Digital Marketplace Commerce plugin retained
- Scroll reveal animations, floating hero animation, hover micro-interactions
- Keyboard shortcut Ctrl/Cmd + K for search
- Reduced-motion support

## Installation
1. Upload `digital-marketplace-pro-v4.0.0.zip` from WordPress Admin > Appearance > Themes > Add New > Upload Theme.
2. Activate the theme.
3. Keep the bundled `digital-marketplace-commerce` plugin active if your store uses its custom products/cart/checkout/download functionality.
4. Go to Settings > Permalinks and click Save Changes.

## Notes
The theme is designed to work with the existing custom `product` post type and `product_cat` taxonomy when the bundled commerce plugin is active. Product pricing and metadata continue to use the existing marketplace fields.
